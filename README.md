# Gacha Tracker 0.5.3

基于 0.5.0 原界面做局部升级，不再重写整体 UI。

## 0.5.3
- 保留 0.5.0 的统计、筛选、卡池封面和按钮布局
- 抽卡记录改成小型网格卡片，减少占用空间
- 抽卡记录显示：角色图片 → 角色名 → 第几抽
- 角色库支持为角色导入图片
- 去掉角色备注栏和抽卡备注栏
- 抽卡角色来源始终是整个角色库
- UP池只设置 UP 角色，不再设置“可能抽到的角色”
- UP角色数量不限
- UP池抽到非UP角色自动判定为歪，底色标红
- 普池和其他池不判断歪卡
- 修改UP角色后，既有记录的歪卡状态会按当前UP名单动态重新判断
- 修复旧版 saveData 无限递归问题
- 兼容旧数据：旧UP池的 characterIds 会迁移为 upCharacterIds
