# Gacha Tracker 0.6.0

- “总抽数”改为“总招募次数”
- “抽卡记录”改为“招募记录”
- 每个卡池新增“当前已垫招募次数（0–39）”
- 总招募次数会把尚未出绝密的招募也算进去
- 卡池显示“距离40次保底还有多少次”
- 招募详情的“第 xx 抽”简化为只显示数字
- “添加记录 / 编辑卡池 / 删除”整合进一个“编辑”入口
- “编辑”按钮放到卡池图片右侧并列显示
- 密探小图由1.2倍改为1.4倍
- 编辑密探时支持左右/上下手动调整图片取景，并实时预览

示例：第38次出绝密，随后又招募2次：
- 绝密记录填 38
- 当前已垫招募次数填 2
- 总招募次数会按 40 计算
- 距离下一次40次保底还有 38 次
