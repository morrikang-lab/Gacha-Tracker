# Gacha Tracker 0.5.2

## 更新内容
- UP池不再设置“可能抽到的角色”，抽卡角色直接来自全部角色库
- 只需为UP池设置UP角色
- 抽到UP角色 = 不歪
- 抽到角色库中其他角色 = 自动判定为歪卡
- 普池不判断歪卡
- 其他池：如果设置UP角色则自动判断，否则不判断
- 角色库支持导入角色图片
- 去掉角色备注
- 抽卡记录缩小卡片尺寸，显示角色图片 / 名字 / 抽数
- 歪卡底色标红
