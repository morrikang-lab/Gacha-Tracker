# Gacha Tracker 抽卡记录器

Obsidian 抽卡记录插件，0.5.0 为 iPad + 坚果云友好版。

## 主要功能
- 总抽数、SSR记录数、平均每个SSR抽数
- UP池 / 普池 / 其他卡池
- 全局角色库
- UP池最多选择2名角色
- 抽卡记录可展开查看、编辑、删除
- UP池支持“歪卡”标记
- 卡池封面图片保存到 Vault 内
- 不依赖 Obsidian Sync，适合坚果云同步 Vault

## 数据位置
插件数据由 Obsidian 保存；封面图片位于：

`Gacha Tracker/images/`

因此整个 Vault 可以通过坚果云同步。

## BRAT 安装
在 Obsidian 安装 BRAT 后，选择“Add Beta plugin”，输入本仓库地址：

`https://github.com/你的用户名/Gacha-Tracker`

然后安装并启用 Gacha Tracker。

## 升级注意
插件 ID 始终保持 `gacha-tracker`，因此 0.4.0 升级到 0.5.0 时会继续使用原来的插件数据。
